# Maivoc

**Every model. One workspace.**

Maivoc is a personal-first AI workspace built on [LibreChat](https://github.com/LibreChat-AI/LibreChat), with optional free-tier cloud providers and private local models.

Status: repository initialized; implementation is being prepared on a review branch. The project is not yet deployed or production-tested.

We preserve and credit the upstream project's MIT license. This is an independent community project, not an official LibreChat release or endorsement.
